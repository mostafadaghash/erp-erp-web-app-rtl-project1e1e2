# Printing Acceptance Artifacts

The A4 invoice PDF, thermal receipt PDF, and A4 screenshot are generated by a real headless Chromium process before the unit test suite runs. Generated files are written to the ignored `test-results/printing` directory, validated for their binary signatures and minimum dimensions, and uploaded by CI as short-lived acceptance evidence.

This automated browser check proves that valid print files can be rendered. It does not replace the physical printer acceptance gate for the target A4 and thermal printers.
