# V1 Pilot Scope Lock

## القرار

الهدف الحالي الوحيد هو تجهيز نسخة Cloud الحالية لتجربة تشغيل فعلية لمدة 14 يومًا في فرع واحد وبعدد محدود من المستخدمين. هذا المستند يمنع تحريك خط النهاية أثناء إغلاق V1.

## داخل نطاق V1

- فاتورة بيع واضحة ومضغوطة ومناسبة للاستخدام بالكيبورد والباركود.
- فتح الفواتير والمستندات القديمة والانتقال منها إلى تفاصيلها.
- المبيعات والمشتريات والمرتجعات الأساسية وربط آثارها الحالية.
- المخزون وحركة الصنف والتكلفة والربح وفق الصلاحيات.
- الخزينة والتحصيل والصرف والتحويلات والتسويات الحالية.
- التقارير الأساسية بفلاتر قابلة للاستخدام وفتح المستند المرتبط عند توفره.
- طباعة A4 والطباعة الحرارية للعمليات المطلوبة.
- تسجيل الدخول والمستخدمون والصلاحيات وسجل العمليات الحساسة.
- نجاح فحوص الكود والبناء والأمان والاختبارات الآلية.
- نجاح Staging UAT والنسخ الاحتياطي والاستعادة قبل الـPilot.

## خارج نطاق V1 ومجمّد

- Windows LAN Edition وPostgreSQL المحلي.
- العمل دون إنترنت أو مزامنة الأجهزة بعد انقطاع الشبكة.
- Setup للجهاز الرئيسي أو الأجهزة التابعة.
- إضافة وحدات تجارية جديدة غير موجودة حاليًا.
- إعادة بناء شاملة أخرى للواجهة بعد اعتماد تصميم V1.
- أي تحسين لا يمنع التشغيل ولا يصحح خطأ بيانات أو حساب أو أمان.

PR #123 يظل Draft مستقلًا ولا يُدمج ضمن مسار V1.

## قاعدة قبول أي تغيير

يُنفذ التغيير قبل الـPilot فقط إذا كان واحدًا من الآتي:

1. يمنع إتمام عملية يومية أساسية.
2. يسبب خطأ في البيانات أو المخزون أو الرصيد أو الحساب.
3. يسبب مشكلة أمان أو صلاحيات.
4. يمنع الطباعة أو فتح المستندات أو التقرير الأساسي المطلوب للتشغيل.

أي اقتراح آخر يُسجل لما بعد الـPilot ولا يوسع النسخة الحالية.

## خط نهاية V1

تدخل النسخة Pilot عندما تتحقق الشروط التالية:

- CI وTypeScript والاختبارات والأمان وProduction Build ناجحة.
- سيناريوهات Staging الأساسية ناجحة بحسابات وصلاحيات مختلفة.
- البيع والتحصيل والمرتجع والمشتريات والمخزون والخزينة متطابقة في الاختبار.
- يمكن فتح المستندات القديمة وطباعتها.
- التقارير الأساسية تعمل بفلاترها المتفق عليها.
- تم تنفيذ تجربة نسخ احتياطي واستعادة موثقة.
- لا يوجد عطل P0 أو P1 مفتوح يمنع التشغيل.

بعد ذلك يبدأ Pilot لمدة 14 يومًا. لا يُعاد فتح قرار Windows/LAN إلا بعد قراءة نتائج الـPilot وإثبات أن الاتصال بالإنترنت عائق تشغيلي فعلي.
