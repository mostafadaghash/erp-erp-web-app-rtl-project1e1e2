# Supplier payments coverage matrix

The supplier-payment integration suite is tracked by stable acceptance IDs SPP-01–SPP-40: partial/full/multi-receipt posting (01–04), exact treasury and supplier effects plus links and numbering (05–10), create idempotency (11–14), validation (15–27), authorization and branch isolation (28–32), rollback (33), reversal/idempotency/links (34–38), paginated history (39), and protected printing (40). Pure rule coverage additionally verifies totals, piastre precision, receipt-state derivation, reversal arithmetic, and canonical allocation ordering.
